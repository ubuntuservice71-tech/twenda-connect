# Acesso administrativo TWENDE
O painel exige uma sessão válida, e-mail confirmado e função admin em public.user_roles. O cliente usa a integração existente e tipos obtidos do esquema real, sem alterar os ficheiros gerados pelo Lovable. Nenhum endereço de e-mail está codificado na interface ou nas políticas. Não criar utilizadores via INSERT em auth.users. O proprietário deve criar a conta pelo Supabase Auth (convite ou registo confirmado) e solicitar atribuição da função admin ao UUID confirmado através de operação privilegiada. Nunca atribuir a função a uma conta não confirmada. Não publicar credenciais. RLS continua a autoridade de acesso aos dados; as operações administrativas permanecem demonstrativas até implementação de autorização no servidor. Build e testes com contas reais pendentes.
