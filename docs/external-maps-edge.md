# Geoapify via Supabase Edge Function
Projecto twenda (ovchyktojhrbydigwmzq), funcao twende-maps v1 ACTIVE, JWT obrigatorio e validacao de conta confirmada no Auth. A chave TWENDE_GEOAPIFY_API_KEY permanece no runtime Supabase. Cliente invoca a funcao via sessao Supabase. Codigo publicado arquivado em docs/edge-functions/twende-maps.ts.txt.
Orcamento piloto persistente map_api_budget, RPC reserve_map_api_budget exclusivo de service_role. 100 unidades por conta/dia UTC, 1000 globais; pesquisa=1, rota=10, mosaico=1. Unidades internas, nao creditos oficiais Geoapify. Limites provisórios nao garantem ausencia de custos externos. Teste SQL de reserva e privilegios revertido.
Pesquisa centrada em Lichinga, restrita a Mocambique. Sem pagamentos ou tarifas comerciais alterados. Sem fallback automatico para OSM. O servidor nao necessita de segredos Lovable. Validacao real autenticada de pesquisa, rotas, mapas, cobertura, termos e quotas do fornecedor pendente. Changelog markdown indisponivel; documentacao Auth consultada.
