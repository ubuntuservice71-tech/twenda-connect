Home starts with destination search, saved shortcuts, service choices and map entry; separate route step, vehicle/offer step with map auto-opening after explicit Continue and disclosure, then review. Existing route button retained rather than automatic route recalculation to manage pilot quotas. Map can be opened manually during search. Bottom navigation Home, Services, Activity, Account; wallet accessible under Account. No decorative yellow cards; yellow primary actions and identity retained. Preserve request validation, public map access, guest review and auth-required submission. No DB, auth, payment, package or generated file changes. Existing ride tracking and identity modules retained, no simulated ETA, GPS positions, photos, or calls. Saved places are session-only; leaving booking via tabs may reset draft. Map provider and visual/physical mobile acceptance unverified. Prior CI passed. Updated tests cover staged progression and preserving price on return.
